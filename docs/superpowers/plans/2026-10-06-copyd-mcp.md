# Copyd MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development. Work through the tasks in order.

**Goal:** A local, token-protected MCP server inside the Mac app that lets Claude Code, Cursor and other MCP clients search and read clips, list pinboards and, optionally, copy text.

**Architecture:**
- Pure units in `Copyd/MCP/`: `HTTPRequestParser`, `MCPRequestGuard`, `MCPRouter` and `MCPTools`.
- An `NWListener`-based `MCPServer` bound to 127.0.0.1.
- A `StoreClipLibrary` over a background `ModelContext`.

**Tech Stack:** Swift 6 strict concurrency, Network.framework, Security (Keychain), SwiftData, SwiftUI, String Catalogs (en/es), XcodeGen. The Mac targets macOS 14+.

**Spec:** `docs/superpowers/specs/2026-10-06-copyd-mcp-design.md`

## Review Focus

1. **A web page in the user's browser can't reach the server.** That covers DNS rebinding, a foreign `Origin` and a missing token. Pinned by `MCPRequestGuardTests` and the loopback 403 and 401 tests.
2. **A secret is never returned,** not through search, `get_clip` by id, or board counts. Pinned by `StoreClipLibraryTests.testSecretsAreInvisible`.
3. **Malformed or huge requests never crash or hang the app.** That covers truncated headers, giant bodies, slowloris connections, invalid JSON and wrong JSON-RPC shapes. Pinned by `HTTPRequestParserTests` and the router error tests.
4. **The token never ends up in history or logs.** The copy buttons use skip capture, and the logs redact the token. Pinned by code review and a test on the `Logger` call sites if feasible.
5. **Clients actually work.** Pinned by the orchestrator's `curl` and `claude mcp add` run after install.

### Task 1: Sandbox spike, then the server core

**Files:**
- `Copyd/MCP/HTTPRequestParser.swift`, `MCPRequestGuard.swift`, `MCPRouter.swift`, `MCPTools.swift`, `MCPServer.swift`
- `Copyd/MCP/ClipLibrary.swift`, which holds the protocol and its value types
- Tests: `HTTPRequestParserTests`, `MCPRequestGuardTests`, `MCPRouterTests`, `MCPServerLoopbackTests`. The loopback tests use a fake `ClipLibrary`.

**Interfaces:**
- `protocol ClipLibrary: Sendable`. All of its calls are async:
  - `search(query: String?, type: ClipKind?, board: String?, limit: Int) async throws -> [ClipSummary]`
  - `clip(id: UUID) async throws -> ClipDetail?`
  - `boards() async throws -> [BoardSummary]`
  - `copy(text: String) async throws`
- `MCPRouter(library:, allowsWrite: @Sendable () -> Bool)`, with `func handle(_ body: Data) async -> MCPResponse`. `MCPResponse` is `.json(Data)` or `.accepted`.
- `MCPRequestGuard.check(host:origin:authorization:port:token:) -> GuardResult`, where `GuardResult` is `.ok`, `.forbidden` or `.unauthorized`.
- `MCPServer(port:, token:, router:)`, with `start() throws` and `stop()`. Its `state` is `.off`, `.running(port)` or `.failed(String)`, and it calls `onStateChange`.

**Steps:**
- [ ] **Spike.** In the scratchpad, outside the repo, build a tiny Swift CLI that binds `NWListener` to `127.0.0.1:39787` and answers `200 OK`.
  - Ad-hoc sign it with `com.apple.security.app-sandbox` and `com.apple.security.network.server`, run it, and `curl` it.
  - Record the result in the report. If the sandbox blocks it, STOP and report BLOCKED.
- [ ] Write the failing tests:
  - the parser: limits, partial reads, `Content-Length` required, 413, 431;
  - the guard: each host and origin case, a wrong or missing token, constant-time comparison;
  - the router: `initialize` and its version negotiation, `ping`, `tools/list` with and without write, each `tools/call` against the fake, unknown method `-32601`, invalid JSON `-32700`, notifications 202;
  - loopback: 200, 401, 403, 404, 405 and 413 on an ephemeral port.
- [ ] Implement the units and the server.
  - All I/O runs on a serial `DispatchQueue`.
  - Close a connection after 30 s idle.
  - Allow at most 8 connections.
  - Never log the token.
- [ ] Verify: the suite and the Mac build.
- [ ] Commit: `[feat] Add a local MCP server core for Copyd`

**Interfaces:**
- **Settings keys** (in `.standard`):

  | Key | Default |
  |---|---|
  | `mcpServerEnabled` | false |
  | `mcpServerPort` | 39787 |
  | `mcpAllowsWrite` | false |

- **Search** follows spec §3:
  - It matches `textContent`, `ocrText`, `linkTitle` and file names, case- and diacritic-insensitive. Match in memory over a predicate-bounded fetch of the newest 2000 non-secret clips if SwiftData predicates can't do diacritic-insensitive matching.
  - `board` resolves a user pinboard by name, case-insensitive, or a `SmartBoard` raw value, using the existing smart-board predicates.
- **Smart boards** use `SmartKinds` and `SmartBoard` from round 2.

**Steps:**
