# Copyd iOS App and Paste Keyboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a universal iPhone/iPad app that syncs the Copyd history through the existing CloudKit code, plus a keyboard extension that pastes that history into any app.

**Architecture:** The models, the sync engine and the thumbnailer move to a `Shared/` folder that the Mac app, the iOS app and the keyboard all compile. The iOS app runs `CloudSyncEngine` against a SwiftData store in the App Group, and the keyboard opens the same store read-only. Every decision the keyboard and the app make goes into a pure, unit-tested function: store path, feed, paste action and relative sync time.

**Tech Stack:** Swift 6 (strict concurrency complete), SwiftUI, SwiftData, CloudKit `CKSyncEngine`, ImageIO, UIKit (`UIInputViewController`), XcodeGen, XCTest. macOS 14+ and iOS 17+.

**Spec:** `docs/superpowers/specs/2026-10-02-ios-app-design.md`. Read it with the sync spec, `docs/superpowers/specs/2026-10-01-icloud-sync-design.md`.

## Global Constraints

- Deployment targets: macOS 14.0, iOS 17.0. Swift 6 with `SWIFT_STRICT_CONCURRENCY: complete` on every target. No new SPM dependencies.
- Identity: iOS app bundle `com.robbyfuu.copyd` (the same as the Mac app); keyboard `com.robbyfuu.copyd.keyboard`; App Group `group.com.robbyfuu.copyd`; iCloud container `iCloud.com.robbyfuu.copyd`; team `TQC76W2BKK`.
- Shared defaults: suite `group.com.robbyfuu.copyd`, key `lastSyncAt` (a `Date`).
- Keyboard limits: feed limit 60; text preview at most 300 characters; insert threshold 51_200 UTF-8 bytes, inclusive. File clips never appear.
- The Mac's behavior and data do not change. `StoreManager` and its store constants stay exactly as they are.
- Colors come only from `DesignTokens.Brand`. Views use no literal colors (`Color.clear` is fine).
- After every SwiftData mutation, call `try? modelContext.save()` (UI code). Sync code uses `do`/`catch` with logging. Every sync-layer write goes inside `tracker.suppressing(ids)`.
- Commits use `[type] what and why`, with no `Co-Authored-By` line. Use `/usr/bin/git`; plain `git` is blocked in this worktree.
- Every `xcodebuild` and `xcodegen` call is prefixed with `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` and uses `-derivedDataPath DerivedData`. Builds:
  - Mac: `xcodebuild -project Copyd.xcodeproj -scheme Copyd -configuration Debug -derivedDataPath DerivedData -allowProvisioningUpdates build`
  - iOS simulator: `xcodebuild -project Copyd.xcodeproj -scheme CopydiOS -configuration Debug -destination 'generic/platform=iOS Simulator' -derivedDataPath DerivedData build`
  - Tests: `xcodebuild test -project Copyd.xcodeproj -scheme CopydTests -destination 'platform=macOS' -derivedDataPath DerivedData`. Baseline: 146 passing.
- Nothing is created in the Apple Developer account before Task 8's gate. Tasks 1–7 build for the simulator, or for macOS, only.

## Review Focus

1. **The keyboard is opened before the app has ever run.** The store file does not exist yet, and the keyboard must show "Open Copyd once…" instead of crashing or creating an empty store. Pinned by `SharedStoreTests.testStoreExistsIsFalseWithoutFile` (Task 4), and the keyboard consults it in Task 7.
2. **Keyboard memory with a history full of large images.** The feed must never load `rawData`. Pinned by `KeyboardFeedTests.testFeedCarriesThumbnailNotRawData` (Task 4): `KeyboardClip` has no raw-data field, and the image thumbnail is passed through.
3. **Very long text or a large text preview.** The preview is capped at 300 characters, and inserting is decided by byte size, not by character count. Pinned by `KeyboardFeedTests.testTextPreviewCappedAt300` and `PasteActionTests.testMultibyteTextUsesByteCount` (Task 4).
4. **iCloud sign-out on iOS.** All local clips, pinboards and entries are removed, and nothing echoes back to iCloud. Pinned by `RemoteApplierTests.testDeleteAllRemovesEverythingAndReportsIDs` (Task 3).
5. **The thumbnail rewrite changes orientation or sizing.** Pinned by the existing `ThumbnailTests`, which must stay green unchanged after the ImageIO rewrite (Task 2).

Known limitation, not fixed here: copying an old clip on the iPhone reaches the Mac through Universal Clipboard, and the Mac captures it as a new clip at the top. The duplicate rule only merges copies within 60 s. Task 8 observes this and records it.

**Interfaces:**
- Produces:
  ```swift
  enum SharedStore {
      static func url(groupContainer: URL) -> URL            // <container>/Library/Application Support/Copyd/Copyd.store; creates the directory
      static func storeExists(groupContainer: URL) -> Bool
      static var groupContainer: URL? { FileManager.default.containerURL(forSecurityApplicationGroupIdentifier: SharedDefaults.suiteName) }
  }
  struct KeyboardClip: Identifiable, Equatable { let id: UUID; let contentType: ContentType; let preview: String; let thumbnail: Data?; let isPinned: Bool; let copiedAt: Date; let textByteCount: Int }
  enum KeyboardFeed {
      enum Mode { case recent, pinned }
      static let limit = 60, previewLimit = 300
      @MainActor static func items(in context: ModelContext, mode: Mode, limit: Int = limit) throws -> [KeyboardClip]
  }
  enum PasteAction: Equatable {
      case insert(String), copyToPasteboard
      static let insertByteLimit = 51_200
      static func decide(contentType: ContentType, text: String?) -> PasteAction
  }
  enum RelativeSyncTime { static func text(from date: Date?, now: Date) -> String }  // nil → "Never synced"; <60 s → "Updated now"; <60 min → "Updated N min ago"; <24 h → "Updated N h ago"; else "Updated N d ago"
  ```
  - `KeyboardClip.preview`:
    - text, rich text and HTML: `textContent`, trimmed and capped at 300 characters;
    - link: the URL text;
    - color: the hex value;
    - image: an empty string.
  - `thumbnail` comes from `thumbnailData`, and only for images.
  - `KeyboardFeed` excludes `.fileURL` clips, sorts by `copiedAt` descending, filters on `isPinned` for `.pinned`, and never reads `rawData`. `textByteCount` is `textContent?.utf8.count ?? 0`.
  - `PasteAction.decide`:
    - `.image` → `.copyToPasteboard`;
    - `.color` → `.insert(hex)` (the hex is in `text`);
    - all other types → `.insert(text)` when `text.utf8.count <= 51_200`, otherwise `.copyToPasteboard`;
    - a nil or empty `text` → `.copyToPasteboard`.
